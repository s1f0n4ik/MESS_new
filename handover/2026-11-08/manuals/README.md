# Актуальные инструкции Postcards

Комплект зафиксирован 8 ноября 2026 года.

- `Postcards Studio Инструкция веб сервиса` — работа с четырьмя документами в браузере, роли, ввод текста, публикация, изменение общего макета и медиации документа 4.
- `Postcards Руководство пользователя` — установка, настройка и эксплуатация десктопного выставочного приложения, роли PC1–PC4, MIDI, обновление PDF и диагностика.
- `Postcards Краткая инструкция для выставки` — сокращенная памятка оператору перед показом и во время выставки.
- `Postcards Инструкция для медиаторов.md` — простая инструкция только по тем действиям, которые доступны медиатору.
- `Postcards Техническое описание и передача` — архитектура, сборка, развертывание, резервирование, доступы, ограничения и границы дальнейшего сопровождения.

PDF предназначены для чтения и передачи. DOCX являются редактируемыми исходниками соответствующих инструкций. При расхождении с кодом необходимо проверять версию по `../VERSION_MANIFEST.md` и фиксировать изменение документации отдельным коммитом.
